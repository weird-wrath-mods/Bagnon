# Bagnon (3.3.5)

Tuller's Bagnon, with a sort button added left of the close/options buttons on the inventory and bank frames. Sort logic ported from shirsig's SortBags.

## Modules

Install only what you want. `Bagnon` is the only required module.

- **Bagnon**: single-window inventory, bank, and keyring. Required.
- **Bagnon_Config**: in-game GUI for tweaking frame layout, colors, slots shown, etc. Skip if you're happy with defaults.
- **Bagnon_Forever**: remembers each character's bag and bank contents so you can browse them while logged onto another character.
- **Bagnon_Tooltips**: adds "you have X on alt Y" lines to item tooltips. Requires Bagnon_Forever.
- **Bagnon_GuildBank**: replaces the Blizzard guild bank UI with a Bagnon-style window. Disabled by default; enable in your AddOns list.
